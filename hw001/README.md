(표는 Turtle 을 사용하시오)

## 파일별 상세 설명

### 1. `main.py` (메인 실행 파일)
* **역할**: 프로그램의 진입점(Entry Point)이자 전체 데이터 흐름을 제어하는 컨트롤러.
* **주요 기능**:
  * `file_io.py`를 호출하여 `health.txt` 데이터를 파싱하고 데이터 구조화.
  * `bmi_calc.py`를 호출하여 각 레코드에 대한 BMI 수치 및 비만도 소견을 계산해 데이터 추가.
  * `drawer.py`를 호출하여 최종 가공된 데이터를 Turtle 그래픽 표 형식으로 화면에 시각화.

### 2. `file_io.py` (데이터 입출력 모듈)
* **역할**: 외부 텍스트 파일(`health.txt`) 탐색, 읽기, 예외 처리 및 파싱.
* **주요 기능**:
  * `os.path`를 활용하여 실행 경로(Working Directory)와 무관하게 `hw001` 폴더 내 `health.txt` 경로를 동적으로 자동 탐색.
  * 파일 저장 인코딩 방식(`UTF-8`, `CP949`)에 따른 `UnicodeDecodeError` 방지 및 파일 부재 시 예외 처리 (`FileNotFoundError`).
  * 텍스트 파일 내 헤더 행(제목) 및 공백 라인을 걸러내고, 각 행의 데이터(전화번호, 이름, 키, 몸무게)를 딕셔너리(`dict`) 형태의 리스트로 구조화하여 반환.

### 3. `bmi_calc.py` (BMI 연산 & 비만도 판정 모듈)
* **역할**: 신장 및 체중 데이터를 바탕으로 체질량지수(BMI)를 계산하고 비만도를 판정하는 비즈니스 로직 처리.
* **주요 기능**:
  * **계산식**: $\text{BMI} = \frac{\text{몸무게}(\text{kg})}{\text{키}(\text{m})^2}$ (소수점 둘째 자리에서 반올림 처리).
  * **판정 기준**: 대한비만학회(KSSO) 성인 비만 진단 기준 적용.
    * `18.5 미만`: 저체중
    * `18.5 이상 ~ 23.0 미만`: 정상
    * `23.0 이상 ~ 25.0 미만`: 과체중 (비만전단계)
    * `25.0 이상 ~ 30.0 미만`: 비만 (1단계 비만)
    * `30.0 이상`: 고도비만

### 4. `drawer.py` (Turtle 그래픽 출력 모듈)
* **역할**: Python `turtle` 모듈을 활용하여 데이터를 시각적으로 정렬된 그래픽 표로 렌더링.
* **주요 기능**:
  * 표 헤더("전화번호", "이름", "키 (cm)", "몸무게(kg)", "BMI", "소견") 생성 및 구분선 렌더링.
  * 각 열(Column)별 너비(`col_widths`) 및 X/Y 좌표 계산을 통해 데이터가 일정한 간격으로 깔끔하게 맞춰 출력되도록 정렬.
  * 결과 화면 출력이 끝난 후 창이 바로 닫히지 않도록 이벤트 루프 실행 (`screen.mainloop()`).

### 5. `health.txt` (입력 데이터 파일)
* **역할**: 회원들의 건강 데이터가 들어있는 원본 파일.
* **구조**: 첫 줄은 항목 이름(헤더)으로 구성되며, 이후 각 줄마다 공백으로 구분된 전화번호, 이름, 키(cm), 몸무게(kg) 데이터 수록.

### 6. `result.png` (실행 결과 캡처 파일)
* **역할**: Turtle 창에서 정상 작동한 그래픽 표 출력 화면 캡처 이미지.
